# System working rules
The owner selected adoption of the WikiHouse structural system on 2026-09-23. Read docs/SYSTEM_RULES.md and docs/WIKIHOUSE_SOURCE_LOCK.json. This supersedes the independent-frame direction; archive/independent-frame-v02 preserves that study. Existing dist/ remains the historical frame until the replacement is validated.
Use pinned official WikiHouse components and connections together. Do not invent joinery, resize source parts arbitrarily, combine release generations or imply engineering approval. Preserve original geometry, IDs, units, source notices and attribution. CNC offsets and dog-bones may already be applied; inspect the source before processing.
Reuse the v74 Rhino8 offline export workflow. New GH import/export wrappers must not be represented as official WikiHouse parametric definitions. Verify source CAD against exported meshes and report actual validation limits.
Keep Studio and Architecture unchanged unless requested. GitHub changes use the GitHub plugin only. No supplier outreach without authorization. Package/Drive updates only when requested. End progress reports with clear continuation options, as the owner requested. Do not ask again for routine authorized work.
