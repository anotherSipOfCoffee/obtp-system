# Brand strategy - recommendation, not approval
Use one OBTP parent with distinct descriptive product identities. Working labels: Studio, Houses, System. Rationale: build repeated recognition around one parent; give each audience a clear purpose; avoid three independent awareness/acquisition efforts. Different visual treatments and separate URLs can coexist with a shared parent. Keep R&D readiness explicit to avoid implying the system is already used by the house/studio. Shared reputation also means shortcomings can transfer between products.
This is a strategic inference for this early-stage related portfolio, not a measured conversion result. Test whether a new visitor can identify each product and its readiness. Split brands later only if audience, ownership, channel or positioning creates demonstrable confusion.
Cross-links: Related OBTP projects or sibling projects; do not imply independent commercial partners. Final naming and cross-link wording await owner acceptance.
