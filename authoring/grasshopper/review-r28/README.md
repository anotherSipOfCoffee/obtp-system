# R28 worked examples

Run `python authoring/grasshopper/REVIEW_R28.py` with rhino3dm installed to regenerate the local visual review and portable Sauna model. The downloadable ZIP bundles these generated files; Git retains the generator, summary and guide.

These new generic configurations are not replacements for the earlier saved Sauna/Studio models. Their quantities cannot be used as a same-design optimization comparison: programmes, details, windows, equipment and weathering scope differ.
