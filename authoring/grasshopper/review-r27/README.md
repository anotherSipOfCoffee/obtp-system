# R27 review evidence

`before-after.csv` compares the 24 saved preset/roof cases with frozen R26. No geometry or primary/cladding quantity change is intended.

Run `python authoring/grasshopper/REVIEW_R27.py` with rhino3dm installed to generate the local HTML review, SVGs, timing measurements and Studio M portable 3DM. These generated visual/model assets are bundled in the downloadable ZIP; Git retains the generator and compact evidence rather than duplicate model exports. The HTML is a local review document, not a deployed website.
